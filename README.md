# 📂 Prova de GitHub 

## Sobre o projeto

Este repositório foi criado como parte de uma atividade prática realizada no início do curso, com o objetivo de testar os conhecimentos básicos sobre o GitHub e a criação de repositórios.

A atividade consistiu na criação de um repositório e no envio de um arquivo HTML (`index.html`) para praticar os primeiros passos utilizando a plataforma.
